# Show do Chopão — V2

Interface inspirada na linguagem visual de game shows clássicos de perguntas e respostas, com:
- fundo azul;
- pergunta em painel vermelho;
- quatro respostas em botões vermelhos numerados;
- área inferior com ERRAR / PARAR / ACERTAR;
- escada lateral de 15 valores;
- identidade própria “Show do Chopão”.

## Deploy no Vercel
Suba os arquivos da raiz no GitHub e importe o repositório no Vercel como projeto estático.
