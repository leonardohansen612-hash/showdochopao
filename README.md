# Show do Chopão — Prévia

Prévia estática e interativa do game show do Tex Pub.

## Como subir no GitHub + Vercel

1. Crie um repositório novo no GitHub.
2. Envie `index.html`, `styles.css` e `script.js` para a raiz.
3. No Vercel, importe o repositório.
4. Framework Preset: `Other`.
5. Não precisa de Build Command.
6. Faça o deploy.

## O que já funciona

- 15 perguntas.
- Escada de R$ 10 até R$ 500.
- Seleção de alternativas.
- Botões de acertou/errou.
- Próxima/anterior.
- Timer de 30 segundos.
- Ajuda 50/50.
- Animação de acerto.
- Layout responsivo.
